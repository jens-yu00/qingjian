# macOS 个人定制

状态：功能已实现，原生窗口与代码检查通过；系统输入源启用尚未成功，实机验收待继续。详见 [验证记录](../notes/personal-macos-validation.md)。

## 目标与当前事实

- 面向本机 macOS 使用，让候选窗口适合视力较弱的用户，并支持中文模式英文标点。
- 基线为上游 main 的 `57aa14947d93330e0df83e661fd2323a9a2bb196`。
- 候选字、译文、序号当前分别为 16、12、11 pt，尚无大小设置。
- main 已提供“默认中文标点”的全角／半角设置；普通拼音组句中敲标点仍会进入英文直输。
- 用户明确要求 fork 并做好 Git 管理。fork 已创建为 `jens-yu00/qingjian`。

## 已确认的体验

1. 候选窗口整体缩放，初始 150%，提供设置入口。实现为 100%–250%、每档 25%；候选字、窗口内拼音、译文、序号、图标及间距同步缩放。应用内行内拼音不受影响。
2. 使用 Option + Shift + 句号切换中文模式的英文／中文标点，在青简激活的各应用中共享同一个设置并保存，切换时显示提示。英文模式原有按键行为不变。
3. 不改变组句、候选确认、翻页或英文直输语义。组句中按快捷键只切换标点偏好，不上屏、不清空输入、不重新选择候选；长按只切一次。

## Git 管理方案

- `upstream` 指向 `qingjian-team/qingjian`，`origin` 指向用户 fork。
- `main` 保持上游基线，定制在 `codex/macos-personal-customization` 分支进行。
- 获取完整上游历史，便于追踪和同步；按职责提交，只暂存本次改动。
- 使用仓库现有检查钩子；测试通过后推送定制分支，核对本地与远端提交哈希。

## 实现边界

- 复用原生候选窗口和现有设置通路，避免新增界面框架或另建配置文件。
- 英文标点开关复用上游已有全角／半角设置作为唯一状态，增加切换快捷键；保留上游所有组句与上屏语义。
- 用户可感知的行为同时更新用户文档；词汇放根目录 CONTEXT.md。当前尚无需要单独 ADR 的难以逆转决定。

## 验证与交付

- 新行为先以可复现失败说明缺口，再验证实现后的通过结果。
- 配置：默认值、旧配置缺项、合法边界、非法值处理、保存与热加载。
- 显示：横排与竖排、不同缩放、高亮区域（上游候选窗口不接收鼠标点击）、长候选、屏幕边缘；真实截图检查裁切和布局。
- 标点：已上屏中文后的半角输出；快捷键切换不改变组句与当前候选，英文直输与原有标点输入保持原样。
- 执行相关单元测试、格式和 Clippy 检查；打包后验证本机输入，不把单元测试等同于系统集成测试。
- 实际试用使用上游产品词库与模型，并核验下载校验和；只带仓库样例数据的构建不能代表日常体验。
- 安装前核查已有青简安装；如需替换，备份现有应用与配置并记录回退方式。
- 记录安装路径、构建哈希、测试结果和未验证项目；任何无法验证的系统行为明确列为证据缺口。

## 失败处理

- 配置无效沿用项目既有错误处理；缩放不得导致非有限尺寸或零尺寸。
- 构建、测试或数据校验失败时先处理失败，不交付为可用版本。
- 安装或输入法注册失败时保留构建产物与诊断信息，不自动注销会话。
