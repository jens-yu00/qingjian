# Sol 2B 本机试用

用户决定先安装 Sol 2B 试用。本页落实[语境挑战者](llm-first-homophones.md)的决策模型接入部分，完整语境学习仍另行实现。

- 基础候选即时显示；停键 80 ms 后，在本机 MLX 常驻进程比较最多 12 个完整、精确、相同音节的词典候选。无上文、简拼、拼写变体不请求。
- Sol 的决策头返回整批 logits；分数不能按单词缓存或套用旧字级模型的 logP 加权。领先原首选至少 1.0，且领先第二名至少 0.1，才提升一个词；基础词频超过挑战者 100 倍时对原首选的门槛提高至 2.0，明确语境仍可突破。
- 个人习惯保留在基础排序，模型近似平局不干预。试用不实施新的语境学习；接受模型提升的词不累计裸词频，避免预测自我强化。
- 输入、上文、会话变化使结果作废；开始移动高亮或翻页后冻结。每个稳定输入只决策一次，2 秒过期后不再采用该结果。异常保留基础候选。
- `[model] sol = true` 选择此试用后端，`enabled` 是总开关。Sol 替换旧字级模型的同音词决策，试用不加载旧模型。关闭 Sol 恢复原后端。

## 本地进程契约

Rust 适配器用绝对路径启动安装目录中的 Python 和 `worker.py`，不经 shell、不监听网络。Python 从 `model/` 验证并载入固定 Sol q4 bundle，预热后 stdout 写 `{"ready":true}`。

之后每行一个 JSON 请求：`{"context":"…","pinyin":"shiyan","texts":["实验","食盐"]}`。响应 `{"scores":[0.0,2.0]}` 必须与整个请求候选顺序等长且全为有限数。一次仅一个在途请求，失败返回空分数；协议/进程失败或响应超过 2 秒，Rust 结束子进程，本次启用不重试。加载限 60 秒。关闭模型/父进程退出结束子进程。上文不写文件和日志，环境强制离线。

## 验证与边界

用 Core 实际候选验证合法性、异步生命周期、平局/强语境、冻结与错误学习抑制；通过真实 Sol 进程回放公开案例，另测失效/超时。保留 `keneng/yange/diyige/liuchu` 回归。安装只复制应用，不注册或切换输入源，由用户系统设置启用验收。

阈值 1.0 是现有小样本的试用取舍，须记录真实接入回放结果；不是独立千例验收或误改率 ≤0.5% 的结论。候选缺词仍需词典修复，模型不创造词条。
