# yange / diyige 自动组句抢占首选的诊断与修复（2026-10-14）

状态：已复现并修复严格全拼下的整句插入优先级。保留学习数据；该修复不依赖外接决策模型，新语境学习规则仍未实施。安装与实机回执见 [验证记录](personal-macos-validation.md)。

## 确认到的行为

用户期望“第一个”，实际首选“的一个”。仅筛选这两个文本的本机输入日志，确认出现了 `keys=diyige`、`pinyin=di'yi'ge`、`source=sentence`、`top[0]=的一个`、`top[1]=第一个`。既有神经重排后的错误，也有未重排时的错误，不能归因于单一神经模型。

产品词库本身有 `第一个 / di yi ge`，不是缺词。干净 CLI 使用相同产品词库、bigram、随包小模型与严格全拼，`diyige`、`dyg`、`dyige`、`diyig` 首选均为“第一个”。

把当前学习文件复制到被忽略的 `target/verification/ordinal-personal/` 后，同一条 `diyige` 查询稳定输出“的一个”首选、“第一个”第二。CLI 的写回目标只设为副本，未对当前输入法数据进行删除或清空。

每组从同一份副本开始，仅省略一张表，其余输入与参数相同：

## 代码侧解释与修复边界

主词库中“的”同时有 `de` 和较低频的 `di`。`sentence::viterbi` 查询词图时保留了输入读音，但语言模型与个人 n-gram 按词文本计分；已认识的字词使用语言模型分，不再使用那个读音的词频作为兜底分。全局个人词频也按文本加分。`engine/query::plain_sentence` 产生整句后，`insert_sentence` 将其放到普通中文词之前；完整词“第一个”的输入串选择偏好不能直接约束这条整句的插入。

这解释了为什么“的 + 一个”能借常用文本与个人统计挤掉一个已存在的完整词。消融证明个人词频与个人 n-gram 的组合触发了这个样例；尚未用最小合成数据证明哪项计分修正能在完整回归集上安全解决它，不能把某个修复猜想写成已证实的唯一根因。

修复应保护读音与完整词的竞争关系，保留个人学习。不要直接禁掉“的一个”、删除“的”的 `di` 读音或清空用户记录：`deyige` 的“的一个”以及“的确／目的／的士”等都需继续可用。

修复验收需要：把当前失败缩成可公开的最小数据；覆盖无模型与神经重排、同步与异步、正确完整词的精确选择偏好；检查 `deyige` 合法组句、多音字正常用法、既有 `keneng/jineng/heneng` 回归。安装后仍由用户启用和实机确认。


## yange 的同类复现与修复

本机输入日志记录了 `yange → 样哦` 首选、“严格”第二，包含已重排和未重排两种情况。产品词库同时支持 `yan ge`（严格）和 `yang e`（样 + 哦）；`哦/e` 是现有词典读音，因此这里的错误是歧义切分后的组合优先级，不是拼音字母被改写。

复制学习数据到 `target/verification/yange-personal/`，真实词库与随包模型稳定复现“样哦 / 严格”和“的一个 / 第一个”。不加载个人数据、不加载模型也会出现“杨阿 / 严格”和“的一个 / 第一个”，说明个人统计会放大问题，但并非触发自动组句抢占的必要条件。

修复位于 Core 的 `insert_sentence`：严格全拼时，普通整句组合放在完整命中的中文词之后。逐音节核对全部完整切分，保留词级排序结果；无完整词时仍让整句组合优先。保留 `yang'e` 的显式音节边界和 `deyige` 的合法表达，不增加字符串黑名单、不清空任何学习表。未来专用模型对完整组合的挑战仍须满足独立验收门槛，不能靠插入位置取得首选权限。

公开最小测试位于 `engine/tests/sentence_priority.rs`：修改实现前，“样哦抢占严格”和“的一个抢占第一个”两项失败，“未收录组合可输入”通过；修复后全部通过，Core 共 324 项通过。前两项分别覆盖歧义切分和强个人词频，另检查显式分隔符及完整上屏。

产品 CLI 加载个人数据副本，在无神经模型、同步神经重排、异步神经重排三种运行方式下，首选均为 `yange → 严格`、`diyige → 第一个`；`deyige → 的一个`、`dique → 的确`、`mudi → 目的`、`keneng → 可能`、`jineng → 技能`、`heneng → 核能`、`xiangkaifa → 想开发` 均通过，`dishi` 仍能选择“的士”。日志在 `target/verification/sentence-priority-{plain,neural,async}.log`。

修复仅取消自动组句的无条件置顶：例如当前数据下“样哦”仍在后面的组合候选中。多音字统计仍按文本计分，带语境的新学习设计尚未实施；不能把这次修复宣称为已经解决所有语义误选。
