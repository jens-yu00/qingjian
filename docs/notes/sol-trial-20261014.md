最终只剩“对数组进行 bianli”无法选出“遍历”：该词不在本轮候选池中。原标签另把“免费 shiyong”只标作“试用”；复核接受同样自然的“使用”，保留两套计数，不改原始结果。

第一轮采用“领先第二名至少 1.0”，只有 88/92：明显否定原首选后，还可能因为两个挑战者接近而保留错误原词。最终门槛改为领先原首选 1.0（压倒性词频保护为 2.0），领先第二名 0.1；“收集／统治／意识”恢复正确，“形式”未被错误换成“行事”。**这是在同一公开小样本上调整的试用门槛，不能视为独立测试通过了误改率 ≤0.5% 验收。**

## 行为与验证

- 接入前在完整后台状态已搭好的基础上，故意尚未放行提升，真实 Core 查询的“实验 → 食盐”断言失败；接通排序后通过。不是既有上游行为的 bug 复现。
- Core 专用决策测试覆盖：即时基础候选与一次合法提升、弱分及非有限数、输入改走再改回、上文/会话变化、导航前后冻结、无上文/隐私/简拼不请求、超时不再获权、高频保护可突破、近似挑战者不挽救已被否定的原词、预测接受不累计裸词频且不错误撤销旧学习。
- 本地进程测试通过真实 stdin/stdout 验证分数顺序、损坏协议、无 ready、响应超时后终止；真实模型完成两轮公开回放，结束后未遗留模型进程。
- 旧的 `keneng/yange/diyige/liuchu` 相关 Core 回归保留；整套检查与本机安装验收记录见本页交付条目。
- 试用中个人旧偏好参与基础排序；模型近似平局保持基础排序。只阻断接受已提升词的预测回声，包含直接选中该提升词也暂不学习；手动改选其他词继续原规则。按语境存储偏好、主动/被动事件的完整分权、衰减与负信号尚未实现。
